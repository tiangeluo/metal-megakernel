Inside the two-layer decoder

Follow one token through adjacent local and global layers, modeled on layers 10 and 11 of Inkling 2 Small (zero-indexed). The first layer updates the state that the second layer reads. Each layer has its own convolution histories and KV cache.

What the attention kernel does

For the new token, clip Q and the relative features, convolve then clip K, and convolve then RMS-normalize V without a learned scale. Append K/V at cache precision. Each KV head serves six query heads. Add the learned relative-position term for distances under 1,024, include the token’s zero-value sink in the softmax denominator, then apply the sigmoid output gate.

What we scale

The two-layer stack uses hidden width 1,152, expert width 576, 12 query heads and two KV heads. Head dimension stays 128. Each layer routes to eight of 384 independent softcapped SwiGLU experts. The expert weights across both layers occupy about 2.85 GiB in FP16, excluding router weights, attention weights and working buffers.

Four schedules for one token

Every schedule starts with the same raw projected token features and cache history. It returns the gated attention output, the new K/V entries and the updated Conv4 histories. The full-cache scan reads the exact rounded K/V that future steps will see.

Compiled MLXCompile preparation and gating around fast grouped-query SDPA. Include relative-bias construction. At batch one pass the current per-head sink. For multiple sequences, fold batch into the head axis so each sequence retains its own six-to-one grouping and per-head sink. Verify the chosen execution path in a trace.
Staged MetalEncode preparation, scan and gating in one command buffer. Share math, tiling and work assignment with the single-dispatch version. This isolates the effect of removing boundaries and intermediate writes.
HybridUse custom Metal preparation and Conv4 history updates, then append the rounded K/V via MLX, run tuned attention and apply the gate. Include interop, memory layout changes and synchronization in elapsed time.
Single-dispatch MetalOne threadgroup owns one KV head and its six query heads for one sequence. It prepares K/V, appends one cache slot, streams KV tiles with online softmax and gates the output. Batch one gives eight independent groups at the published geometry.
Why a longer context could change the winner

A single dispatch removes handoffs, but eight groups may leave useful parallelism on the table. At contexts 64 and 4,096, also test a native scan split across context tiles with a second reduction. Compare it at the same precision before attributing a long-context difference to parallelism.

Measurement contract

Each comparison uses the same precision policy across its four attention schedules. The connected control keeps expert weights in FP16 and performs expert arithmetic in FP32. Generate test inputs and initialize caches outside the timed region. Restore identical starting states for fixed-length trials, rotate representative seeded tokens and routes, warm each compiled shape, and collect at least 100 synchronized samples per reported cell. Measure host-to-completion consistently, tracing representative native GPU intervals separately. Record software revisions, power mode and thermal conditions. Report fallbacks, failures and unstable cells alongside the winners.
