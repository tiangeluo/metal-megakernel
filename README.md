# Original study history

This Git bundle preserves the nine original commits for the M4 Pro experiments, including the first pilot at `29cf099` and the study-note release at `1988277`. Download [metal-megakernel-history.bundle](metal-megakernel-history.bundle), then clone it locally.

```sh
git clone metal-megakernel-history.bundle study-history
git -C study-history log --oneline
```

The [main branch](https://github.com/tiangeluo/metal-megakernel/tree/main) contains the runnable code, raw trials and article.
